# 0018: 英文作为文档主版本

[English](../../04-decisions/2026-09-14-0018-english-primary-documentation.md) | **简体中文**

- 状态：accepted
- 日期：2026-09-14
- 相关：[文档规范](../03-engineering/09-documentation-standards.md)

## 背景

【事实】仓库原先的项目 README、设计文档、ADR 与供应商指南使用中文，代码与发布的 crate 文档使用英文（原文档规范第 1 节）。

## 决策

【决策】英文为主版本，位于 `README.md` 与 `docs/`。完整、独立的中文版位于 `README.zh-CN.md` 与 `docs/zh-CN/`，保持对应文件名、章节结构、ADR 编号与待验证编号。两版内容冲突时以英文为准。依据：英文读者获得一致的默认入口，同时保留中文文档。

【决策】各版内部链接指向同语言章节，通过明确入口切换语言。源码、fixture、资源与生成的 `docs/api/*.json` 共用，避免复制实现产物。

【决策】英文使用 `[Fact]`、`[Decision]`、`[Pending verification]`，中文使用【事实】、【决策】、【待验证】。契约、决策或验证结果变更时在同一次变更中同步两版，保留来源、日期与验证范围。

## 备选方案

- 【决策】英文放在可选的 `docs/en/` 下：不符合英文作为默认主版本的要求，未采用。
- 【决策】每页交错放置中英文：不符合两版独立阅读的要求，未采用。

## 影响

【决策】同步更新文档规范、贡献指南、代理规则、索引与文档检查。翻译不改变 SDK 行为、公共 API、依赖版本或已有待验证事项状态。
