# 0026：与参考 SDK 的行为对齐

[English](../../04-decisions/2026-09-17-0026-reference-sdk-parity.md) | **简体中文**

- 状态：proposed
- 日期：2026-09-17
- 相关：ADR 0003、0005、0012、0013、0020、0021；[逐模块对齐核查](../05-appendix/03-reference-parity.md)

## 背景

【事实】Ferrin Agent 与本地 Vercel AI SDK 的 `6c6c221` 提交采用相同的工具循环架构，但在按名称分发工具上下文、动态供应商工具解析、调用准备、回调调度及流消费方面存在差异（来源：`ferrin-core/src/agent`、`generate_text`、`stream_text`；参考项目 `packages/ai/src/agent` 和 `generate-text`，2026-09-17 检查）。

【决策】以此固定提交核查 Ferrin 的全部现有模块。范围为现有十八个 crate 及其已实现的 API 族。新增供应商、前端协议模块、Code Mode、Harness 和 Workflow 属于独立范围，不作为现有模块对齐的前提。

## 决策

【决策】对照对应参考实现及测试，匹配支持的输入、默认值、准备阶段优先级、状态转换、供应商请求、结果、错误和流边界。命名与 Rust 所有权采用本语言的表达；剩余可观察差异必须逐项记录。方法名相同或既有测试通过，均不足以证明行为对齐。

【决策】工具上下文先按工具名选择，再校验 schema；没有 context schema 时仍传递选中的值。不论是否注册了其他工具，均接受未声明的供应商执行动态调用，并执行输入精炼。普通未知本地工具拒绝及 caller 限制保持有效。

【决策】扩展调用准备的可覆盖配置，并提供可选调用参数 schema 校验。显式调用 timeout 最终优先。步骤准备提供初始指令及配置的模型实例，允许仅当前步骤的 sandbox 覆盖。生命周期回调并发执行并等待全部结束，单个回调失败不得阻止其他回调完成。

【决策】等待最终流结果时主动驱动调用，并支持独立消费的事件视图，不引入脱离所有者的后台任务。保持所有者取消语义，明确滞后视图引入的缓冲开销。这修订 ADR 0005 的消费契约，但不让未被轮询的 Rust future 自发执行。

【决策】配置的审批回调和策略适配器对齐参考项目对不适用、默认决策、仅观测 shadow 求值的区分。已有签名校验、敏感信息隐藏和安全 URL 策略继续生效。

## 验证

【决策】在逐模块核查中记录参考路径、具体差异及回归证据。只有相关新增回归检查通过后，才能将相应接口标为已验证。本地协议测试与 PV-031 的真实供应商验证分别记录。

【决策】实现变更同步更新双语契约、迁移说明、crate changelog 及生成的 API 快照。本 ADR 记录已授权的实现方向，并在仓库维护者评审前保持 proposed；它不代表所有模块已经对齐。
